Terminos y condiciones

Normas del sistema

Estas reglas definen el uso responsable de la plataforma y se reflejan en validaciones de registro, publicacion, comentarios y perfil.

Reglas de uso

  • El usuario debe registrarse con datos validos.
  • El alias publico debe usarse para identificarse sin exponer el correo.
  • No se permite publicar contenido ofensivo, violento, discriminatorio o de acoso.
  • Las publicaciones deben tener titulo, imagen y categoria.

Politicas de contenido

  • Las imagenes deben respetar derechos de autor y privacidad de terceros.
  • Los comentarios deben mantener un lenguaje respetuoso.
  • El sistema puede bloquear palabras asociadas con acoso, violencia o discriminacion.
  • El contenido se organiza por categorias para mejorar la navegacion responsable.

Responsabilidades del usuario

  • El usuario es responsable del material que sube.
  • No debe compartir datos personales propios o de otras personas en campos publicos.
  • Debe eliminar o corregir contenido que incumpla las normas.
  • Debe usar la plataforma sin afectar la seguridad o privacidad de otros usuarios.

Mecanismos verificables implementados

Privacidad

La interfaz publica muestra alias, foto y biografia, pero no muestra el correo del usuario.

Control de publicacion

La subida de fotos exige imagen, titulo y categoria antes de continuar.

Moderacion basica

JavaScript bloquea palabras no permitidas y correos en campos publicos.

Confirmacion

Antes de eliminar una publicacion se solicita confirmacion al usuario.
